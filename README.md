# Читач — українська бібліотека на GitHub Pages

## Що є
- Статичний сайт у `index.html`: пошук за назвою/автором/жанром, передперегляд тексту, завантаження TXT.
- `catalog.json` — каталог книжок.
- GitHub Actions для щоденного пошуку кандидатів у Вікіджерелах.
- GitHub Actions для автоматичної публікації сайту через GitHub Pages.
- `reader-app-original.html` — копія попереднього застосунку, збережена окремо.

## Публікація на GitHub з iPhone
1. У репозиторії `chytach-library` відкрий у Safari `https://github.com/ТВІЙ-ЛОГІН/chytach-library/upload/main` (заміни логін).
2. На сторінці Upload files вибери файли з розпакованої папки та завантаж їх у корінь репозиторію. ZIP не завантажуй як один файл. Якщо iPhone не дозволяє вибрати всі файли/папки, найпростіше відкрити GitHub у Safari з режимом «Запитати настільний вебсайт» або використати комп'ютер.
3. Натисни Commit changes.
4. Перейди Settings → Pages і вибери **GitHub Actions** як Build and deployment source.
5. Перейди Actions: запусти workflow «Опублікувати сайт Читач на GitHub Pages». Після успіху сторінка покаже URL, зазвичай `https://ТВІЙ-ЛОГІН.github.io/chytach-library/`.
6. В Actions запусти «Оновити каталог книжок». Дозволь workflow write access: Settings → Actions → General → Workflow permissions → Read and write permissions.

## Обмеження
- GitHub Pages — статичний хостинг: немає власного сервера, бази даних, акаунтів користувачів, оплати або приватного API.
- У репозиторії та Pages усе публічне. Не зберігай паролі, токени або приватні файли.
- Імпортер шукає кандидатів у Вікіджерелах; не кожен результат є повною книжкою і не кожен статус прав визначається автоматично. Файли з `licenseStatus: needs_review` слід перевірити перед публічним розповсюдженням.
- Спочатку формат TXT. GitHub має обмеження на великі файли/репозиторії; для великої колекції варто перенести файли в окреме сховище.
- Автоматичний імпорт може не знайти жодної книжки або завершитися помилкою, якщо джерело недоступне. Перевір Actions → logs.
